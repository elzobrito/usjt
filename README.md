# USJT — atividades de sala

Arquivo comum das turmas. Cada matéria tem a sua pasta; cada oferta vive no semestre.

```text
<materia>/<AAAA-S>/atividades/
```

- `<materia>` — slug ASCII da UC (sem acento, sem espaço)
- `<AAAA-S>` — ano e semestre, por exemplo `2026-2`
- `atividades/` — o que o estudante abre (enunciado, HTML, exercício)

Apostila, PDF e gabarito ficam **fora** deste repositório.

## Como acrescentar uma atividade

1. Abra `<materia>/<AAAA-S>/atividades/`.
2. Se a matéria ou o semestre ainda não existirem, crie a pasta no mesmo padrão.
3. Atualize o README da matéria e esta tabela, se for oferta nova.

## Como o estudante usa

Clone ou baixe o ZIP. Entre na pasta da **sua** matéria e do **seu** semestre. Abra o `README.md` da oferta e os arquivos de `atividades/`.
