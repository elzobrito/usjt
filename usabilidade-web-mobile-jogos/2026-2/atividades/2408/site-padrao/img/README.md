# Imagens

Coloque aqui fotos e o logotipo (JPG, PNG, SVG, WebP).

No HTML, use caminho relativo:

```html
<img src="img/fachada.jpg" alt="Fachada da loja à luz do dia, com a porta aberta">
```

O `alt` descreve o que a imagem informa. Imagem só decorativa: `alt=""`.

Não suba captura com dado pessoal (documento, saldo, tela de conversa).
