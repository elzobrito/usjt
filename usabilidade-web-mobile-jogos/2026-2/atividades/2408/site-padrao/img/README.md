# Imagens

Coloque aqui fotos e o logotipo (JPG, PNG, SVG, WebP). No modelo, a pasta vem vazia: só este README.

No HTML, use caminho relativo, sem barra no começo:

```html
<img src="img/fachada.jpg" alt="Fachada da loja à luz do dia, com a porta aberta">
```

O `alt` descreve o que a imagem informa. Se a imagem for só decorativa, use `alt=""`.

Colocar uma foto real na home ou no Sobre, com `alt` descritivo, é um dos extras permitidos no enunciado ([../../atividade-site.md](../../atividade-site.md)).

Não suba captura de tela com dado pessoal (documento, saldo, conversa).
