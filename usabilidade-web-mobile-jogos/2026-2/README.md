## Atividade 1 — IHC

Enunciado completo em `atividades/atividade1.md`.

- **Duração:** 30 minutos (plano B: 20)
- **Formato:** individual
- **Produto:** 1 slide ou 1 página com o mapa visual + frase de registro

Escolha um sistema que você **já usa**. Não invente um sistema ideal. Avalie as qualidades de uso com evidência na interface, não com opinião solta.

Não exponha dados da sua conta (saldos, documentos, capturas com informação pessoal).

## Aula 04 — Consulta de escolas

A tela pedida é simples: título **Consulta de escolas**, uma caixa **Núcleo Regional** e uma caixa **Período**.

Ordem sugerida:

1. Abra `atividades/codigo.html` e descreva o que a tela faz — e o que ela não faz.
2. Abra `atividades/cpdogp2.html`. Os furos são **outros**.
3. Abra `atividades/codigo3.html`. O código parece certo no papel; o navegador compara letra por letra.

Em cada rodada: circule o problema, diga o que quebra na tela e proponha o conserto em uma linha.

Tese da aula: o HTML estrutura, o CSS veste. Nenhum dos dois fabrica a lista do Período.

## Site no GitHub Pages

Enunciado em `atividades/atividade-site.md`. O aluno copia `atividades/site-padrao/`, troca os textos entre `[colchetes]`, altera só o `:root` das cores e publica a pasta como raiz do repositório.

Layout travado (menu, páginas, formulário com `label`). Liberdade: o negócio, o copy e no máximo dois extras da lista. Sem JavaScript.
