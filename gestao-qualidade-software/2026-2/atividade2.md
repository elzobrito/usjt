Atividade 2 — Caça ao defeito: quem encontra o bug que passou pelo teste?
Situação

Vocês fazem parte da equipe de qualidade responsável por liberar uma pequena página para produção.

O desenvolvedor afirma:

“Está funcionando no meu computador.”

O objetivo não é simplesmente corrigir o código.

O objetivo é descobrir quantos problemas diferentes podem existir em algo aparentemente simples.

Organização

Divida a turma em equipes.

Cada equipe recebe uma versão diferente do HTML fornecido pelo professor.

Nenhuma equipe sabe se recebeu o mesmo código das outras.

Missão

A equipe possui 8 minutos para realizar uma inspeção.

Para cada problema encontrado, deverá registrar:

onde está o problema;
qual é o defeito;
qual seria o efeito percebido;
quem poderia perceber o problema;
como poderia ter sido prevenido.

Utilizem esta classificação:

D — Defeito: existe algo incorreto no artefato.

F — Falha: o comportamento observado pelo usuário está incorreto.

Q — Problema de qualidade: mesmo funcionando, existe alguma característica inadequada.

Regra especial

Não ganha a equipe que encontrar mais erros.

Ganha a equipe que apresentar a melhor justificativa para o problema mais importante encontrado.

Segunda rodada

Depois dos oito minutos, troque os códigos entre as equipes.

Agora cada grupo recebe a análise realizada por outro grupo e possui cinco minutos para responder:

O grupo anterior deixou algum problema passar?

Essa segunda etapa simula uma revisão independente.
